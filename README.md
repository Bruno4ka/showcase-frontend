# Витрина проектной деятельности (Фронтенд)

Фронтенд-приложение для "Витрины проектной деятельности" — дашборд для просмотра и анализа данных продаж с серверной пагинацией, фильтрацией, сортировкой и поиском.

## Быстрый старт

### Стек технологий:

- **JavaScript (ES2022)**
- **Vite 6.0.5**
- **HTML5 / CSS3**

### Требования для начала работы

- **Node.js 20+**
- **npm 10+**
- **Git**
- **VS Code** (рекомендуется) / любой редактор
- **Современный браузер** (Chrome, Firefox, Edge)

### Клонирование репозитория

**Через VS Code (проще):**
- `Вкладка Source Control (Ctrl+Shift+G) → Clone Repository → в поле URL вставить ссылку на репозиторий → выбрать директорию → Clone`

**Через терминал:**
```bash
# Перейти в папку для проектов
cd D:\Projects

# Клонировать репозиторий
git clone ссылка_на_репозиторий smart-table

# Перейти в папку проекта
cd smart-table
